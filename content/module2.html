Программа задаёт себе вопросы

В игре всё время что-то проверяется. Хватает ли монет на меч? Закончилось ли здоровье? Правильный ли ответ? На такие вопросы есть только два ответа: да или нет.

В Python «да» — это True (правда), а «нет» — False (ложь). Python сам отвечает на вопрос, если записать его как сравнение:

print(5 > 3)
print(5 < 3)
print(10 == 10)
print(10 != 10)

Вывод:
True
False
True
False

Знаки сравнения

знаквопроспримерответ
>больше?5 > 3True
<меньше?5 < 3False
>=больше или равно?3 >= 3True
<=меньше или равно?4 <= 3False
==равно?2 + 2 == 4True
!=не равно?2 + 2 != 4False

Два знака равно

Это самое важное в уроке. Один знак = кладёт значение в коробку. Два знака == спрашивают: «это одинаковое?». Перепутать их — очень частая ошибка.

coins = 50              # положить 50 в coins
print(coins == 50)      # спросить: в coins лежит 50?
print(coins >= 100)     # спросить: монет 100 или больше?

Вывод:
True
False

Сравнивать можно и текст

answer = "Париж"
print(answer == "Париж")
print(answer == "париж")

Вывод:
True
False

Для Python большая и маленькая буква — разные буквы, поэтому «Париж» и «париж» не равны.

Если…, то…

Теперь программа умеет ответить «да» или «нет». Осталось научить её что-то делать, когда ответ «да». Для этого есть слово if — по-английски «если».

health = 0

if health == 0:
    print("Игра окончена")

Вывод:
Игра окончена

Читается так: «если здоровье равно нулю, то напечатай „Игра окончена“».

Как это записывается

  • Сначала слово if, потом вопрос, потом двоеточие :.
  • Следующая строчка начинается с 4 пробелов. Так Python понимает, что эта команда выполняется только если ответ «да». Thonny сам ставит пробелы после двоеточия, когда нажимаешь Enter.

Поменяй health = 0 на health = 30 и запусти. Ничего не напечатается: ответ на вопрос «нет», и строчка с отступом пропускается.

Несколько команд внутри if

Все строчки с отступом выполняются только при «да». Строчка без отступа выполняется всегда.

coins = int(input("Сколько у тебя монет? "))

if coins >= 100:
    print("Ты купил меч!")
    coins = coins - 100
    print("Осталось монет:", coins)

print("Пока!")

Пока!

Пока!

Что делать, если «нет»

С одним if программа что-то делает при «да», а при «нет» молчит. Но часто нужно сделать что-то и в другом случае: правильный ответ — похвалить, неправильный — сказать, что ошибся. Для этого есть else — «иначе».

answer = input("Столица Франции? ")

if answer == "Париж":
    print("Правильно!")
else:
    print("Нет, это Париж")

Столица Франции? Лондон
Нет, это Париж

Программа идёт только по одной дороге: либо по той, что под if, либо по той, что под else. Обе сразу не выполнятся никогда.

У else нет своего вопроса, только двоеточие. Он пишется на одном уровне с if, без отступа.

Отступ — это часть кода

Во многих языках пробелы в начале строчки ни на что не влияют. В Python — влияют. Отступ показывает, какие строчки «лежат внутри» if, а какие — снаружи.

Посмотри на две программы. Они отличаются только одним отступом:

health = 50

if health == 0:
    print("Ты проиграл")
    print("Попробуй ещё раз")

Вывод: (ничего)

health = 50

if health == 0:
    print("Ты проиграл")
print("Попробуй ещё раз")

Вывод:
Попробуй ещё раз

Во второй программе print("Попробуй ещё раз") без отступа. Значит, он не внутри if и выполняется всегда.

Правила

  • После строчки с двоеточием : идёт отступ.
  • Отступ — 4 пробела. Клавиша Tab в Thonny тоже ставит 4 пробела.
  • Все строчки внутри должны иметь одинаковый отступ.
  • Чтобы выйти из if, просто пиши следующую строчку снова от левого края.

if внутри if

Внутри if может быть ещё один if. Тогда у него свой отступ, ещё на 4 пробела дальше:

has_key = input("Есть ключ? (да/нет) ")

if has_key == "да":
    print("Ты открыл дверь.")
    answer = input("Войти в тёмную комнату? (да/нет) ")
    if answer == "да":
        print("В комнате сундук с золотом!")
    else:
        print("Ты остался в коридоре.")
else:
    print("Дверь закрыта. Ищи ключ.")

Когда двух дорог мало

Игрок набрал очки. За 0–49 он «Новичок», за 50–99 «Боец», за 100 и больше «Герой». Тут три варианта, а if с else дают только два.

Для этого есть elif — сокращение от else if, «иначе если».

score = int(input("Сколько очков? "))

if score >= 100:
    print("Звание: Герой")
elif score >= 50:
    print("Звание: Боец")
else:
    print("Звание: Новичок")

Как Python это читает

Python проверяет вопросы по очереди, сверху вниз. Как только находит первый ответ «да», выполняет эту часть и пропускает всё остальное.

  • Если очков 120: первый вопрос «да», печатается «Герой». Остальное пропускается.
  • Если 70: первый вопрос «нет», второй «да», печатается «Боец».
  • Если 10: оба вопроса «нет», работает else.

Поэтому порядок важен. Если поставить проверку score >= 50 первой, то и 120 очков дадут звание «Боец».

elif можно писать сколько угодно раз. else в конце можно и не писать.

Два условия сразу

Иногда одного вопроса мало. Дверь открывается, только если есть ключ и ты стоишь рядом. В Python для этого есть три слова.

and — «и»

Ответ «да», только если оба вопроса «да».

coins = int(input("Монет: "))
level = int(input("Уровень: "))

if coins >= 100 and level >= 5:
    print("Можно купить огненный меч")
else:
    print("Нужно 100 монет и 5 уровень")

or — «или»

Ответ «да», если хотя бы один вопрос «да».

answer = input("Продолжить? ")

if answer == "да" or answer == "Да":
    print("Продолжаем!")
else:
    print("Выход")

Тут программа поймёт ответ и с большой, и с маленькой буквы.

not — «не»

Переворачивает ответ: «да» становится «нет», и наоборот.

name = input("Имя героя: ")

if not name == "":
    print("Привет,", name)
else:
    print("Ты не ввёл имя")

Число в промежутке

Часто нужно проверить, что число между двумя другими. Это можно записать коротко, как в математике:

age = int(input("Возраст: "))

if 10 <= age <= 15:
    print("Тебе в младшую лигу")

Помнишь «тринадцать»?

В модуле 1 ты вводил слово вместо числа, и программа падала с ошибкой. В настоящей игре так нельзя: игрок ошибся клавишей, и всё сломалось. Теперь, когда ты знаешь if, это можно исправить.

Это цифры?

У строк есть команда isdigit(). Она отвечает True, если строка состоит только из цифр.

print("13".isdigit())
print("тринадцать".isdigit())
print("1 3".isdigit())

Вывод:
True
False
False

Значит, перед int() можно проверить, что ввели именно число:

age = input("Сколько тебе лет? ")

if age.isdigit():
    age = int(age)
    print("Через 5 лет тебе будет", age + 5)
else:
    print("Нужно ввести число цифрами")

Большие и маленькие буквы

Игрок может ответить «Да», «ДА» или «да». Чтобы не проверять все варианты, сделай ответ маленькими буквами через lower(), а потом сравнивай:

answer = input("Хочешь сыграть? ").lower()

if answer == "да":
    print("Начинаем!")
else:
    print("Ну ладно")

Лишние пробелы

Ещё игрок может случайно нажать пробел. strip() убирает пробелы в начале и конце строки. Можно делать всё сразу: input("...").strip().lower().

Рисунок по заказу

Соединим черепашку с if. Игрок выбирает фигуру, а программа рисует то, что он выбрал.

figure = input("Что нарисовать? (квадрат / треугольник / круг) ").lower()

pensize(4)

    color("blue")
    forward(100)
    left(90)
    forward(100)
    left(90)
    forward(100)
    left(90)
    forward(100)
elif figure == "треугольник":
    color("green")
    forward(100)
    left(120)
    forward(100)
    left(120)
    forward(100)
elif figure == "круг":
    color("red")
    circle(50)
else:
    write("Не знаю такую фигуру", font=("Arial", 16))

done()

Светофор

Цвет тоже можно выбирать через if. Команда dot(80, "red") рисует закрашенный круг диаметром 80.

from turtle import *

signal = input("Можно идти? (да / нет) ").lower()

hideturtle()

if signal == "да":
    dot(80, "green")
else:
    dot(80, "red")

done()

hideturtle() прячет черепашку, чтобы она не закрывала рисунок.
