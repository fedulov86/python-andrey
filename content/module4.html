Зачем свои команды

Ты уже пользовался готовыми командами: print, input, forward. Такие команды называются функциями. А ещё можно делать свои.

Представь: в игре в нескольких местах нужно нарисовать рамку из звёздочек. Можно каждый раз копировать три строчки. А можно один раз научить Python новой команде frame и потом просто её вызывать.

def frame():
    print("*" * 20)
    print("*      ИГРА      *")
    print("*" * 20)

frame()
print("Добро пожаловать!")
frame()

Вывод:
********************
* ИГРА *
********************
Добро пожаловать!
********************
* ИГРА *
********************

Как это записывается

  • def (от define — «определить») говорит: «сейчас я объясню новую команду».
  • Потом имя команды, пустые скобки и двоеточие.
  • С отступом — что команда делает.

Важно: сама строчка def ничего не выполняет. Она только запоминает, что делать. Команда срабатывает, когда ты её вызываешь: пишешь имя и скобки, frame().

Поэтому def пишут в начале программы. Вызвать команду, которую ещё не объяснили, нельзя: будет NameError.

Команда с настройкой

У forward(100) в скобках число — сколько шагов пройти. Это параметр: настройка, которую передают команде. Своим функциям тоже можно давать параметры.

def greet(name):
    print("Привет,", name)
    print("Рад тебя видеть!")

greet("Андрей")
greet("папа")

Вывод:
Привет, Андрей
Рад тебя видеть!
Привет, папа
Рад тебя видеть!

name в скобках — это переменная внутри функции. При вызове greet("Андрей") в неё кладётся "Андрей".

Функция, которая отвечает

До сих пор функции что-то делали: печатали, рисовали. Но бывает нужно, чтобы функция что-то посчитала и отдала ответ. Как len("Андрей") отдаёт 6, а input() отдаёт то, что ввёл игрок.

Для этого есть return — «вернуть».

def damage(power, weapon):
    return power * 2 + weapon

hit = damage(10, 5)
print("Урон:", hit)
print("Урон с мечом получше:", damage(10, 12))

Вывод:
Урон: 25
Урон с мечом получше: 32

Вызов damage(10, 5) как будто превращается в число 25. Его можно положить в переменную, напечатать или посчитать с ним дальше.

Ответ «да» или «нет»

Функция может возвращать True или False. Такие функции удобно ставить прямо в if:

def can_buy(coins, price):
    return coins >= price

coins = 80

if can_buy(coins, 50):
    print("Покупаем щит")
if not can_buy(coins, 100):
    print("На меч не хватает")

return заканчивает функцию

Как только выполняется return, функция сразу заканчивается. Строчки после него не выполнятся.

Большой рисунок из маленьких команд

Сложный рисунок трудно нарисовать одним куском. Но его можно разбить на части: дом, дерево, солнце. Для каждой части — своя функция. Потом собираем из них сцену.

from turtle import *

speed(0)

def move(x, y):
    penup()
    goto(x, y)
    pendown()

def square(size):
    for i in range(4):
        forward(size)
        left(90)

def triangle(size):
    for i in range(3):
        forward(size)
        left(120)

def house(x, y, size):
    move(x, y)
    color("brown")
    square(size)
    move(x, y + size)
    color("red")
    triangle(size)

def sun(x, y):
    move(x, y)
    dot(80, "gold")

house(-200, -100, 100)
house(0, -100, 60)
sun(200, 150)

hideturtle()
done()

Посмотри: функция house внутри себя вызывает другие функции — move, square, triangle. Так и строят большие программы: из маленьких понятных кусочков.

Закрашенные фигуры

Чтобы фигура была закрашена, перед рисованием пишут begin_fill(), а после — end_fill(). Цвет заливки задаёт fillcolor:

from turtle import *

fillcolor("yellow")
begin_fill()
for i in range(4):
    forward(100)
    left(90)
end_fill()

done()

Больше одной черепашки

До сих пор на экране была одна черепашка. Для игры понадобится несколько: одна — игрок, другая — звезда, третья пишет счёт. Новую черепашку создают так:

from turtle import *

hero = Turtle()
hero.shape("turtle")
hero.color("green")

enemy = Turtle()
enemy.shape("circle")
enemy.color("red")

hero.forward(100)
enemy.left(180)
enemy.forward(100)

done()

Turtle() создаёт новую черепашку, и мы кладём её в переменную hero. Чтобы дать команду именно ей, пишем имя, точку и команду: hero.forward(100). Точку ты уже видел у строк: name.upper().

Формы и место

Форма может быть "turtle", "circle", "square", "triangle", "arrow". Чтобы поставить черепашку в другое место без линии, сначала поднимают карандаш:

from turtle import *

star = Turtle()
star.shape("circle")
star.color("gold")
star.penup()
star.goto(150, 100)

done()

Черепашка-писатель

Удобно завести отдельную невидимую черепашку, которая только пишет текст:

from turtle import *

writer = Turtle()
writer.hideturtle()
writer.penup()
writer.goto(-200, 150)
writer.write("Очки: 0", font=("Arial", 20))

done()

Программа ждёт нажатий

До сих пор программа выполнялась сверху вниз и заканчивалась. В игре по-другому: программа ждёт, что сделает игрок, и отвечает на его действия.

Для этого черепашке говорят: «когда нажмут такую клавишу, выполни такую функцию».

from turtle import *

shape("turtle")
penup()

def go_up():
    setheading(90)
    forward(20)

def go_down():
    setheading(270)
    forward(20)

def go_left():
    setheading(180)
    forward(20)

def go_right():
    setheading(0)
    forward(20)

onkey(go_up, "Up")
onkey(go_down, "Down")
onkey(go_left, "Left")
onkey(go_right, "Right")
listen()

done()

Запусти, щёлкни по окну черепашки и нажимай стрелки.

Что тут нового

  • setheading(90) разворачивает черепашку в нужную сторону: 0 — вправо, 90 — вверх, 180 — влево, 270 — вниз.
  • onkey(go_up, "Up") — «когда нажмут стрелку вверх, вызови go_up». Обрати внимание: имя функции пишется без скобок. Мы не вызываем её сейчас, а говорим, что вызвать потом.
  • listen() — «начни слушать клавиатуру».

Клавиши-буквы пишут как есть: "a", "w". Пробел — "space".

Задачи

  2. Добавь клавиши: "r" — красный карандаш, "b" — синий, "space" — поднять или опустить карандаш.
  3. Добавь клавишу "c", которая стирает рисунок командой clear().
  4. Сделай управление клавишами W, A, S, D вместо стрелок.

Где щёлкнули

Мышь работает так же, как клавиши: говоришь, какую функцию вызвать при щелчке. Отличие одно: функция получает два параметра — координаты места, куда щёлкнули.

from turtle import *

Щёлкай по окну: черепашка будет ползти к каждому месту и рисовать линию. Получается рисовалка.

Движение без нажатий

В играх многое двигается само: падают предметы, ходят враги. Для этого нужен таймер: «через столько-то миллисекунд вызови функцию».

from turtle import *

shape("turtle")
penup()

def tick():
    forward(5)
    if xcor() > 300:
        goto(-300, 0)
    ontimer(tick, 50)

tick()

done()

ontimer(tick, 50) значит: «через 50 миллисекунд вызови tick». А tick в конце снова заводит таймер. Получается, что она вызывается 20 раз в секунду, и черепашка ползёт сама. Так устроены все игры: много раз в секунду программа чуть-чуть двигает всё на экране.

Переменная, которую меняет функция

Хочется считать, сколько кругов проползла черепашка. Но если внутри функции написать laps = laps + 1, Python выдаст ошибку. Он считает, что внутри функции свои переменные.

Чтобы функция могла менять переменную снаружи, в начале функции пишут global и имя переменной:

from turtle import *

shape("turtle")
penup()
laps = 0

def tick():
    global laps
    forward(5)
    if xcor() > 300:
        goto(-300, 0)
        laps += 1
        print("Кругов:", laps)
    ontimer(tick, 50)

tick()

done()

  2. Сделай «мячик»: черепашка едет вправо, у края разворачивается и едет влево, и так всё время.

  4. После 5 кругов черепашка останавливается и пишет «Финиш!».

Что за игра

Игрок управляет черепашкой стрелками. На поле появляется звезда. Если черепашка доползла до звезды, игрок получает очко, и звезда прыгает в новое случайное место. На всё есть 30 секунд.

Что должна уметь программа

  1. Тёмный фон, черепашка-игрок, звезда в случайном месте.
  2. Управление стрелками.
  3. Если черепашка близко к звезде — +1 очко, звезда переезжает.
  4. Счёт сверху экрана.
  5. Таймер 30 секунд. Когда время вышло — «Игра окончена» и итоговый счёт.

Как узнать, что черепашка поймала звезду

hero.distance(star) возвращает расстояние между двумя черепашками. Если оно меньше 20, значит они встретились.

Начало, дальше сам

from turtle import *
import random

bgcolor("black")
score = 0

hero = Turtle()
hero.shape("turtle")
hero.color("lime")
hero.penup()

star = Turtle()
star.shape("circle")
star.color("gold")
star.penup()

def move_star():
    star.goto(random.randint(-250, 250), random.randint(-200, 200))

def check():
    global score
    if hero.distance(star) < 20:
        score += 1
        print("Очки:", score)
        move_star()

def go_up():
    hero.setheading(90)
    hero.forward(20)
    check()

# дальше: go_down, go_left, go_right

onkey(go_up, "Up")
listen()
move_star()

done()

Сначала доделай управление и сбор звёзд (пункты 1–3), поиграй. Потом выведи счёт на экран черепашкой-писателем и добавь таймер.
