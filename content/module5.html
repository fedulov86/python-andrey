Когда одной коробки мало

В инвентаре героя меч, щит, зелье и ключ. Можно завести четыре переменные: item1, item2… Но предметов может стать сто, и так делать неудобно.

Для этого есть список — одна переменная, в которой лежит много значений по порядку. Список пишут в квадратных скобках, значения — через запятую:

inventory = ["меч", "щит", "зелье", "ключ"]
print(inventory)
print("Предметов:", len(inventory))

Вывод:
['меч', 'щит', 'зелье', 'ключ']
Предметов: 4

Представь список как полку с ячейками. В каждой ячейке своя вещь, а у ячеек есть номера.

Достать по номеру

Номера начинаются с нуля, как у букв в строке:

inventory = ["меч", "щит", "зелье", "ключ"]
print(inventory[0])
print(inventory[2])
print(inventory[-1])

Вывод:
меч
зелье
ключ

[-1] — последний элемент, как у строк.

Заменить по номеру

inventory = ["меч", "щит", "зелье"]
inventory[0] = "огненный меч"
print(inventory)

Вывод:
['огненный меч', 'щит', 'зелье']

В списке могут лежать и числа: scores = [120, 85, 300].

Пройти по всем

Часто нужно что-то сделать с каждым элементом: показать каждый предмет, проверить каждого врага. Для этого for пишут прямо со списком:

inventory = ["меч", "щит", "зелье"]

print("В рюкзаке:")
for item in inventory:
    print("-", item)

Вывод:
В рюкзаке:
- меч
- щит
- зелье

На каждом повторе в переменной item лежит очередной элемент списка: сначала меч, потом щит, потом зелье.

С номерами

Если нужен ещё и номер, используют enumerate. Он даёт сразу две вещи: номер и элемент.

inventory = ["меч", "щит", "зелье"]

for number, item in enumerate(inventory, 1):
    print(f"{number}. {item}")

Вывод:
1. меч
2. щит
3. зелье

Единица в enumerate(inventory, 1) значит «нумеровать с 1».

Посчитать по списку

prices = [30, 120, 15, 60]
total = 0

for price in prices:
    total += price

print("Всё вместе стоит:", total)

Список, который меняется

Инвентарь в игре не стоит на месте: подобрал предмет — добавился, выпил зелье — пропало. У списков для этого есть команды.

inventory = ["меч"]

inventory.append("щит")       # добавить в конец
inventory.append("зелье")
print(inventory)

inventory.remove("зелье")     # убрать предмет
print(inventory)

Вывод:
['меч', 'щит', 'зелье']
['меч', 'щит']

Можно начинать и с пустого списка: inventory = [].

Есть ли в списке

Слово in отвечает, есть ли элемент в списке. Это удобно в if:

inventory = ["меч", "ключ"]

if "ключ" in inventory:
    print("Ты открываешь дверь")
else:
    print("Дверь заперта")

Если попробовать remove предмет, которого нет, будет ошибка. Поэтому перед удалением проверяй через in.

Магазин

inventory = []
coins = 100

while True:
    print(f"Монет: {coins}. Рюкзак: {inventory}")
    choice = input("Купить: меч (60), зелье (20) или выход? ").strip().lower()
    if choice == "выход":
        break
    elif choice == "меч" and coins >= 60:
        inventory.append("меч")
        coins -= 60
    elif choice == "зелье" and coins >= 20:
        inventory.append("зелье")
        coins -= 20
    else:
        print("Не получится")

Случайный элемент

В модуле 3 ты уже видел random.choice. Теперь понятно, что в скобках у неё был список. Она выбирает из него случайный элемент.

import random

monsters = ["гоблин", "скелет", "волк", "дракон"]
loot = ["монета", "зелье", "старый ботинок", "алмаз"]

print("На тебя напал", random.choice(monsters))
print("Ты нашёл:", random.choice(loot))

import random

Викторина со случайным порядком

Вопросы и ответы можно хранить в двух списках с одинаковыми номерами: вопрос номер 0 — ответ номер 0.

import random

questions = ["Самая большая планета?", "Ближайшая к Солнцу планета?", "Красная планета?"]
answers = ["юпитер", "меркурий", "марс"]

order = [0, 1, 2]
random.shuffle(order)

for n in order:
    reply = input(questions[n] + " ").strip().lower()
    if reply == answers[n]:
        print("Верно!")
    else:
        print("Нет, это", answers[n])

Номер — неудобно

Хранить героя в списке можно: ["Торин", 120, 15, 50]. Но через неделю не вспомнишь, что лежит под номером 2: сила или ловкость?

Для этого есть словарь. В нём у каждого значения не номер, а название. Как в настоящем словаре: слово и его значение.

hero = {
    "name": "Торин",
    "health": 120,
    "strength": 15,
    "gold": 50,
}

print(hero["name"])
print("Золото:", hero["gold"])

Вывод:
Торин
Золото: 50

Как это записывается

  • Словарь пишут в фигурных скобках { }.
  • Внутри пары: название, двоеточие, значение. Пары разделяют запятыми.
  • Название пары называют ключом. Значение достают по ключу в квадратных скобках: hero["gold"].

Менять и добавлять

hero = {"name": "Торин", "gold": 50}

hero["gold"] += 30           # изменить
hero["weapon"] = "топор"     # добавить новую пару

print(hero)

Вывод:
{'name': 'Торин', 'gold': 80, 'weapon': 'топор'}

Проверить, есть ли ключ, можно через in: if "weapon" in hero:

Перебрать словарь

Цикл по словарю идёт по ключам. А items() даёт сразу ключ и значение:

prices = {"меч": 60, "щит": 40, "зелье": 20}

print("Магазин:")
for item, price in prices.items():
    print(f"  {item} — {price} монет")

Вывод:
Магазин:
  меч — 60 монет
  щит — 40 монет
  зелье — 20 монет

Магазин на словаре

С таким словарём магазину больше не нужен длинный elif для каждого товара. Новые товары добавляются одной строчкой.

prices = {"меч": 60, "щит": 40, "зелье": 20, "лук": 50}
coins = 100
inventory = []

while True:
    choice = input(f"Монет {coins}. Что купить? (выход — уйти) ").strip().lower()
    if choice == "выход":
        break
    if choice not in prices:
        print("Такого нет")
    elif coins < prices[choice]:
        print("Не хватает монет")
    else:
        coins -= prices[choice]
        inventory.append(choice)
        print("Куплено:", choice)

print("Рюкзак:", inventory)

Список словарей

Мир из комнат

В текстовых играх мир состоит из комнат. В каждой комнате есть описание и выходы в другие комнаты. Это удобно хранить словарём, где каждая комната — тоже словарь.

rooms = {
    "зал": {
        "text": "Большой зал замка. На стенах факелы.",
        "exits": {"север": "библиотека", "восток": "кухня"},
    },
    "библиотека": {
        "text": "Пыльные книги до потолка.",
        "exits": {"юг": "зал"},
    },
    "кухня": {
        "text": "Пахнет супом. Повар куда-то ушёл.",
        "exits": {"запад": "зал"},
    },
}

current = "зал"

while True:
    room = rooms[current]
    print()
    print(room["text"])
    print("Выходы:", ", ".join(room["exits"]))

    command = input("> ").strip().lower()
    if command == "выход":
        break
    elif command in room["exits"]:
        current = room["exits"][command]
    else:
        print("Туда не пройти")

Как это работает

  • В переменной current лежит название комнаты, где сейчас игрок.
  • rooms[current] достаёт словарь этой комнаты: текст и выходы.
  • Выходы — тоже словарь: направление и куда оно ведёт. Если игрок ввёл направление, которое есть в выходах, current меняется на новую комнату.
  • ", ".join(...) склеивает названия выходов через запятую.

Нарисуй карту на бумаге: квадратики-комнаты и стрелки между ними. С ней гораздо проще писать словарь.

Что делаем

Следующие два урока ты делаешь свою текстовую RPG. Сегодня — мир и предметы. В следующем уроке — бой.

Придумай сюжет. Например: ты просыпаешься в подземелье и надо выбраться. Или: найти потерянный амулет в заброшенном замке. Нарисуй карту на бумаге: 6–8 комнат.

Что должна уметь программа

  1. Комнаты с описаниями и выходами (как в прошлом уроке).
  2. В некоторых комнатах лежат предметы. Команда «взять» кладёт предмет в рюкзак, и он пропадает из комнаты.
  3. Команда «рюкзак» показывает, что у тебя есть.
  4. Одна дверь заперта: пройти можно, только если в рюкзаке ключ.
  5. Есть цель: дойти до выхода с нужным предметом.

Подсказка: предметы в комнате

rooms = {

        "text": "Пустой зал.",

inventory = []

inventory += room["items"]

Добавляем врагов

В некоторых комнатах сидят монстры. Пока монстр жив, пройти дальше нельзя. Нужно сражаться.

Что должна уметь программа

  1. У героя словарь: здоровье, сила, золото.
  2. В некоторых комнатах есть монстр (словарь: имя, здоровье, урон).
  3. Команда «атаковать»: герой бьёт монстра (случайный урон от силы), монстр бьёт в ответ.
  4. Если у героя закончилось здоровье — игра окончена. Если у монстра — он пропадает и оставляет золото.
  5. Зелье из рюкзака восстанавливает здоровье.
  6. Найденный меч увеличивает силу.

Подсказка: один удар

import random

hero = {"health": 100, "strength": 10, "gold": 0}
monster = {"name": "гоблин", "health": 30, "damage": 6, "gold": 15}

def attack(hero, monster):
    hit = random.randint(hero["strength"] // 2, hero["strength"])
    monster["health"] -= hit
    print(f"Ты ударил {monster['name']} на {hit}")
    if monster["health"] > 0:
        hero["health"] -= monster["damage"]
        print(f"{monster['name']} бьёт тебя на {monster['damage']}")

while monster["health"] > 0 and hero["health"] > 0:
    input("Enter — атаковать")
    attack(hero, monster)
    print(f"Твоё здоровье: {hero['health']}")

if hero["health"] > 0:
    hero["gold"] += monster["gold"]
    print("Победа! Золото:", hero["gold"])
else:
    print("Ты погиб...")

Заметь: функция attack меняет словари без global. Словари и списки можно менять внутри функции, если передать их параметром.
