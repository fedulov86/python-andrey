Да или нет

Сравнения

Программа задаёт себе вопросы

В игре всё время что-то проверяется. Хватает ли монет на меч? Закончилось ли здоровье? Правильный ли ответ? На такие вопросы есть только два ответа: да или нет.

В Python «да» — это True (правда), а «нет» — False (ложь). Python сам отвечает на вопрос, если записать его как сравнение:

m2_urok1.py
1
2
3
4print(5 > 3)
print(5 < 3)
print(10 == 10)
print(10 != 10)

Вывод:
True
False

False

Два знака равно

Это самое важное в уроке. Один знак = кладёт значение в коробку. Два знака == спрашивают: «это одинаковое?». Перепутать их — очень частая ошибка.

m2_urok1.py
1
2
3coins = 50              # положить 50 в coins
print(coins == 50)      # спросить: в coins лежит 50?
print(coins >= 100)     # спросить: монет 100 или больше?

Вывод:
True
False

Для Python большая и маленькая буква — разные буквы, поэтому «Париж» и «париж» не равны.
