else — иначе

Две дороги

Что делать, если «нет»

С одним if программа что-то делает при «да», а при «нет» молчит. Но часто нужно сделать что-то и в другом случае: правильный ответ — похвалить, неправильный — сказать, что ошибся. Для этого есть else — «иначе».

m2_urok3.py
1
2
3
4
5
6answer = input("Столица Франции? ")

if answer == "Париж":
    print("Правильно!")
else:
    print("Нет, это Париж")

Столица Франции? Лондон
Нет, это Париж

Программа идёт только по одной дороге: либо по той, что под if, либо по той, что под else. Обе сразу не выполнятся никогда.

У else нет своего вопроса, только двоеточие. Он пишется на одном уровне с if, без отступа.

Чётное или нечётное

Помнишь остаток от деления % из модуля 1? У чётных чисел остаток от деления на 2 равен нулю.

    print("Чётное")
else:
    print("Нечётное")

Задачи

  1. Спроси возраст. Если 12 или больше, напиши «Можно играть», иначе «Подрасти немного».

  3. Задай вопрос «Сколько будет 7 × 8?». Скажи, правильный ли ответ.
    Подсказка

    Ответ из input — это строка. Сравнивай с "56" или превращай ответ в число через int.

  4. Спроси два числа и выведи большее из них.
