Отступы

Почему пробелы важны

Отступ — это часть кода

Во многих языках пробелы в начале строчки ни на что не влияют. В Python — влияют. Отступ показывает, какие строчки «лежат внутри» if, а какие — снаружи.

Посмотри на две программы. Они отличаются только одним отступом:

m2_urok4.py
1
2
3
4
5health = 50

if health == 0:
    print("Ты проиграл")
    print("Попробуй ещё раз")

Вывод: (ничего)

m2_urok4.py
1
2
3
4
5health = 50

if health == 0:
    print("Ты проиграл")
print("Попробуй ещё раз")

Вывод:
Попробуй ещё раз

Во второй программе print("Попробуй ещё раз") без отступа. Значит, он не внутри if и выполняется всегда.

Правила

  • После строчки с двоеточием : идёт отступ.
  • Отступ — 4 пробела. Клавиша Tab в Thonny тоже ставит 4 пробела.
  • Все строчки внутри должны иметь одинаковый отступ.
  • Чтобы выйти из if, просто пиши следующую строчку снова от левого края.
