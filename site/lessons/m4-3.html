return — ответ функции

Функция считает и отдаёт результат

Функция, которая отвечает

До сих пор функции что-то делали: печатали, рисовали. Но бывает нужно, чтобы функция что-то посчитала и отдала ответ. Как len("Андрей") отдаёт 6, а input() отдаёт то, что ввёл игрок.

Для этого есть return — «вернуть».

6def damage(power, weapon):
    return power * 2 + weapon

hit = damage(10, 5)
print("Урон:", hit)
print("Урон с мечом получше:", damage(10, 12))

Вывод:
Урон: 25
Урон с мечом получше: 32

Вызов damage(10, 5) как будто превращается в число 25. Его можно положить в переменную, напечатать или посчитать с ним дальше.

Ответ «да» или «нет»

Функция может возвращать True или False. Такие функции удобно ставить прямо в if:

9def can_buy(coins, price):
    return coins >= price

coins = 80

if can_buy(coins, 50):
    print("Покупаем щит")
if not can_buy(coins, 100):
    print("На меч не хватает")

return заканчивает функцию

Как только выполняется return, функция сразу заканчивается. Строчки после него не выполнятся.
