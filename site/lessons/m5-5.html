Словари

Значения с названиями

Номер — неудобно

Хранить героя в списке можно: ["Торин", 120, 15, 50]. Но через неделю не вспомнишь, что лежит под номером 2: сила или ловкость?

Для этого есть словарь. В нём у каждого значения не номер, а название. Как в настоящем словаре: слово и его значение.

9hero = {
    "name": "Торин",
    "health": 120,
    "strength": 15,
    "gold": 50,
}

print(hero["name"])
print("Золото:", hero["gold"])

Вывод:
Торин
Золото: 50

Как это записывается

  • Словарь пишут в фигурных скобках { }.
  • Внутри пары: название, двоеточие, значение. Пары разделяют запятыми.
  • Название пары называют ключом. Значение достают по ключу в квадратных скобках: hero["gold"].

Задачи

  1. Сделай словарь про себя: имя, возраст, любимая игра, город. Выведи каждое значение с подписью.
  2. Сделай словарь монстра: имя, здоровье, урон. Ударь его: уменьши здоровье на 25 и выведи, сколько осталось.
  3. Спроси у игрока его любимый цвет и добавь его в словарь новым ключом.
  4. Что будет, если попросить ключ, которого нет? Прочитай ошибку. Потом попробуй hero.get("armor", 0).
