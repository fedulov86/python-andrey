24import pgzrun

WIDTH = 600
HEIGHT = 400

x = 300
y = 200

def update():
    global x, y
    if keyboard.left:
        x -= 5
    if keyboard.right:
        x += 5
    if keyboard.up:
        y -= 5
    if keyboard.down:
        y += 5

def draw():
    screen.fill("black")
    screen.draw.filled_circle((x, y), 20, "lime")

pgzrun.go()

Пока держишь стрелку, круг едет. Можно нажать две стрелки сразу и ехать по диагонали. Заметь: вверх — это минус по y, ведь y растёт вниз.

Буквы проверяются так: keyboard.a, keyboard.w. Пробел — keyboard.space.

23import pgzrun

WIDTH = 600
HEIGHT = 400

x = 300

def update():
    global x
    if keyboard.left:
        x -= 5
    if keyboard.right:
        x += 5
    if x < 20:
        x = 20
    if x > WIDTH - 20:
        x = WIDTH - 20

def draw():
    screen.fill("black")
    screen.draw.filled_circle((x, 360), 20, "lime")

pgzrun.go()

Задачи

  1. Добавь управление клавишами W, A, S, D.
  2. Не давай герою уехать за края ни по x, ни по y.
  3. Пока зажат пробел, герой едет в два раза быстрее.
  4. Игра на двоих: один круг управляется стрелками, другой — WASD.
