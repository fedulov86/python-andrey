29from turtle import *

figure = input("Что нарисовать? (квадрат / треугольник / круг) ").lower()

pensize(4)

if figure == "квадрат":
    color("blue")
    forward(100)
    left(90)
    forward(100)
    left(90)
    forward(100)
    left(90)
    forward(100)
elif figure == "треугольник":
    color("green")
    forward(100)
    left(120)
    forward(100)
    left(120)
    forward(100)
elif figure == "круг":
    color("red")
    circle(50)
else:
    write("Не знаю такую фигуру", font=("Arial", 16))

done()

Светофор

Цвет тоже можно выбирать через if. Команда dot(80, "red") рисует закрашенный круг диаметром 80.

12from turtle import *

signal = input("Можно идти? (да / нет) ").lower()

hideturtle()

if signal == "да":
    dot(80, "green")
else:
    dot(80, "red")

done()

hideturtle() прячет черепашку, чтобы она не закрывала рисунок.

Задачи

  1. Добавь в программу с фигурами ещё одну: «звезда».
  2. Спроси размер фигуры. Если он больше 300, напиши «Слишком большая» и не рисуй.
  3. Спроси настроение: «хорошее» — нарисуй жёлтый круг, «плохое» — серый, остальное — синий.
  4. Нарисуй светофор из трёх кругов друг над другом. Тот, что выбрал игрок, горит своим цветом, остальные серые.
    Подсказка

    Между кругами поднимай карандаш и сдвигай черепашку вверх на 100.
