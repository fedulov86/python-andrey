Больше одной черепашки

До сих пор на экране была одна черепашка. Для игры понадобится несколько: одна — игрок, другая — звезда, третья пишет счёт. Новую черепашку создают так:

15from turtle import *

hero = Turtle()
hero.shape("turtle")
hero.color("green")

enemy = Turtle()
enemy.shape("circle")
enemy.color("red")

hero.forward(100)
enemy.left(180)
enemy.forward(100)

done()

Turtle() создаёт новую черепашку, и мы кладём её в переменную hero. Чтобы дать команду именно ей, пишем имя, точку и команду: hero.forward(100). Точку ты уже видел у строк: name.upper().

Формы и место

Форма может быть "turtle", "circle", "square", "triangle", "arrow". Чтобы поставить черепашку в другое место без линии, сначала поднимают карандаш:

Черепашка-писатель

Удобно завести отдельную невидимую черепашку, которая только пишет текст:

m4_urok5.py
1
2
3
4
5

9from turtle import *

writer = Turtle()
writer.hideturtle()
writer.penup()
writer.goto(-200, 150)
writer.write("Очки: 0", font=("Arial", 20))

done()

Задачи

  1. Создай трёх черепашек разных цветов и устрой гонку: каждая проползает вперёд случайное расстояние.
  2. Повтори гонку циклом 20 раз, по чуть-чуть, чтобы было видно движение.
  3. После гонки напиши черепашкой-писателем, кто победил.
    Подсказка

    hero.xcor() возвращает, где черепашка сейчас по горизонтали. У кого больше — тот впереди.
