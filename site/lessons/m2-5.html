Когда двух дорог мало

Игрок набрал очки. За 0–49 он «Новичок», за 50–99 «Боец», за 100 и больше «Герой». Тут три варианта, а if с else дают только два.

Для этого есть elif — сокращение от else if, «иначе если».

if score >= 100:
    print("Звание: Герой")
elif score >= 50:
    print("Звание: Боец")
else:
    print("Звание: Новичок")

Как Python это читает

Python проверяет вопросы по очереди, сверху вниз. Как только находит первый ответ «да», выполняет эту часть и пропускает всё остальное.

  • Если очков 120: первый вопрос «да», печатается «Герой». Остальное пропускается.
  • Если 70: первый вопрос «нет», второй «да», печатается «Боец».
  • Если 10: оба вопроса «нет», работает else.

Поэтому порядок важен. Если поставить проверку score >= 50 первой, то и 120 очков дадут звание «Боец».

elif можно писать сколько угодно раз. else в конце можно и не писать.
