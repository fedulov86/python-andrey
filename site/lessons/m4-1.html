Зачем свои команды

Ты уже пользовался готовыми командами: print, input, forward. Такие команды называются функциями. А ещё можно делать свои.

Представь: в игре в нескольких местах нужно нарисовать рамку из звёздочек. Можно каждый раз копировать три строчки. А можно один раз научить Python новой команде frame и потом просто её вызывать.

8def frame():
    print("*" * 20)
    print("*      ИГРА      *")
    print("*" * 20)

frame()
print("Добро пожаловать!")
frame()

* ИГРА *
********************
Добро пожаловать!
********************
* ИГРА *
********************

Как это записывается

  • def (от define — «определить») говорит: «сейчас я объясню новую команду».
  • Потом имя команды, пустые скобки и двоеточие.
  • С отступом — что команда делает.

Важно: сама строчка def ничего не выполняет. Она только запоминает, что делать. Команда срабатывает, когда ты её вызываешь: пишешь имя и скобки, frame().

Поэтому def пишут в начале программы. Вызвать команду, которую ещё не объяснили, нельзя: будет NameError.

Задачи

  1. Сделай функцию hello(), которая печатает приветствие из трёх строчек. Вызови её 3 раза.
  2. Сделай функцию line(), которая печатает линию из 30 знаков =. Нарисуй ею рамку вокруг своего имени.
  3. Поставь вызов функции выше её def и посмотри, какая будет ошибка.
  4. Сделай функцию menu(), которая показывает меню игры, и вызывай её в цикле while True, пока игрок не выберет «выход». Вспомнить: while True и break — урок 3.6.
