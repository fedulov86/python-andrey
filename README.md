# Python для Андрея

Курс программирования на Python для 13-летнего ученика: 7 модулей, 72 урока, от `print` до своей игры на Pygame Zero.

- `content/moduleN.html` — тексты уроков
- `build.py` — собирает сайт в `site/`
- `check.py` — прогоняет все примеры кода из уроков
- `make_sprites.py` — рисует спрайты для модуля 6
- `deploy.sh` — собрать, проверить и выложить на GitHub Pages
