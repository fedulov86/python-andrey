Звуки

Игра начинает звучать

Где взять звуки

Самый простой способ — сайт sfxr.me. Там можно сделать звуки в стиле старых игр. Нажимай кнопки слева: «Pickup/Coin» — звук монетки, «Explosion» — взрыв, «Jump» — прыжок. Понравился звук — нажми «Export .WAV».

Звуки кладут в папку sounds рядом с файлом игры, как картинки в images. Имена — маленькими английскими буквами: coin.wav, boom.wav.

Проигрываем звук

Звук из файла sounds/coin.wav проигрывается так: sounds.coin.play(). Добавь это туда, где герой подбирает монету:

29import pgzrun
import random

WIDTH = 600
HEIGHT = 400

hero = Actor("hero", (300, 200))
coin = Actor("coin", (100, 100))

def update():
    if keyboard.left:
        hero.x -= 5
    if keyboard.right:
        hero.x += 5
    if keyboard.up:
        hero.y -= 5
    if keyboard.down:
        hero.y += 5
    if hero.colliderect(coin):
        sounds.coin.play()
        coin.x = random.randint(30, WIDTH - 30)
        coin.y = random.randint(30, HEIGHT - 30)

def draw():
    screen.fill("darkgreen")
    coin.draw()
    hero.draw()

pgzrun.go()

Музыка

Фоновую музыку кладут в папку music (файл .mp3 или .ogg) и включают одной строчкой перед pgzrun.go(): music.play("theme"). Она будет играть по кругу.

Задачи

  1. Сделай на sfxr.me три звука: монетка, удар, конец игры.
  2. Добавь их в свою игру с камнями из урока 8.
  3. Сделай звук, который становится выше с каждой монетой. Подсказка: сделай на sfxr несколько похожих звуков.
