Спрайты

Картинки вместо кругов

Что такое спрайт

Спрайт — это картинка, которая двигается по экрану: герой, монетка, враг. В Pygame Zero спрайт называется Actor — «актёр».

Где взять картинки

Мы приготовили набор: скачать sprites.zip. Внутри папка images с картинками:

Названия: hero, coin, enemy, star, heart, rock.

Распакуй архив так, чтобы папка images лежала рядом с файлом игры:

igra1/
  igra.py
  images/
    hero.png
    coin.png
    ...

Свои картинки тоже можно: нарисуй в Paint, сохрани как PNG в папку images. Имя файла — только маленькие английские буквы, без пробелов.

22import pgzrun

WIDTH = 600
HEIGHT = 400

hero = Actor("hero", (300, 200))

def update():
    if keyboard.left:
        hero.x -= 5
    if keyboard.right:
        hero.x += 5
    if keyboard.up:
        hero.y -= 5
    if keyboard.down:
        hero.y += 5

def draw():
    screen.fill("darkgreen")
    hero.draw()

pgzrun.go()
  • Actor("hero", (300, 200)) — создать актёра из картинки hero.png и поставить в точку (300, 200). Расширение .png не пишут.
  • hero.x и hero.y — где он сейчас. Их можно менять.
  • hero.draw() — нарисовать актёра.

Заметь: global больше не нужен. Мы не кладём в hero новое значение, а только меняем его x и y.

Если появилась ошибка No image found like 'hero', значит папка images лежит не там. Проверь, что она рядом с файлом игры.

  2. Не давай герою уйти за край экрана.
  3. Нарисуй в Paint свою картинку 50 на 50 точек и сделай её героем.
