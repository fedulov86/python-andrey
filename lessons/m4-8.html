Движение без нажатий

В играх многое двигается само: падают предметы, ходят враги. Для этого нужен таймер: «через столько-то миллисекунд вызови функцию».

14from turtle import *

shape("turtle")
penup()

def tick():
    forward(5)
    if xcor() > 300:
        goto(-300, 0)
    ontimer(tick, 50)

tick()

done()

ontimer(tick, 50) значит: «через 50 миллисекунд вызови tick». А tick в конце снова заводит таймер. Получается, что она вызывается 20 раз в секунду, и черепашка ползёт сама. Так устроены все игры: много раз в секунду программа чуть-чуть двигает всё на экране.

Переменная, которую меняет функция

Хочется считать, сколько кругов проползла черепашка. Но если внутри функции написать laps = laps + 1, Python выдаст ошибку. Он считает, что внутри функции свои переменные.

Чтобы функция могла менять переменную снаружи, в начале функции пишут global и имя переменной:

shape("turtle")
penup()
laps = 0

def tick():
    global laps
    forward(5)
    if xcor() > 300:
        goto(-300, 0)
        laps += 1
        print("Кругов:", laps)
    ontimer(tick, 50)

tick()

done()

Задачи

  1. Сделай, чтобы черепашка ехала быстрее: меньше миллисекунд или больше шагов.
  2. Сделай «мячик»: черепашка едет вправо, у края разворачивается и едет влево, и так всё время.
  3. Соедини с уроком 6: черепашка всё время ползёт вперёд сама, а стрелки только меняют направление. Это начало «Змейки». Вспомнить: клавиши — урок 4.6.
  4. После 5 кругов черепашка останавливается и пишет «Финиш!».
