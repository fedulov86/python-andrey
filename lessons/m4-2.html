Команда с настройкой

У forward(100) в скобках число — сколько шагов пройти. Это параметр: настройка, которую передают команде. Своим функциям тоже можно давать параметры.

m4_urok2.py

6def greet(name):
    print("Привет,", name)
    print("Рад тебя видеть!")

greet("Андрей")
greet("папа")

Вывод:
Привет, Андрей
Рад тебя видеть!
Привет, папа
Рад тебя видеть!

name в скобках — это переменная внутри функции. При вызове greet("Андрей") в неё кладётся "Андрей".

Несколько параметров

Параметров может быть несколько, через запятую. Передавать их нужно в том же порядке.

12from turtle import *

def square(size, pen_color):
    color(pen_color)
    for i in range(4):
        forward(size)
        left(90)

square(60, "red")
square(120, "blue")

done()

Задачи

  1. Сделай функцию triangle(size) и нарисуй три треугольника разного размера.
  2. Сделай функцию polygon(n, size), которая рисует фигуру с n углами.
  3. Сделай функцию stars(n), которая печатает n звёздочек в строчку. Нарисуй ею лесенку.
