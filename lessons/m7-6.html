Выкладываем на GitHub

Проект в интернете

Твой проект в интернете

Пока все сохранения лежат только на твоём компьютере. Если выложить проект на GitHub, его можно показать кому угодно ссылкой, и он не потеряется, даже если с компьютером что-то случится.

Публикуем

  1. В GitHub Desktop нажми Publish repository вверху.
  2. Галочка Keep this code private: если её оставить, проект увидишь только ты. Чтобы показывать другим, сними её. Реши это вместе с папой.
  3. Нажми Publish repository. Теперь проект есть на github.com в твоём аккаунте.
  4. После каждого нового commit нажимай Push origin, чтобы отправить его на GitHub.

Описание проекта

На GitHub у каждого проекта есть страница с описанием. Её текст берётся из файла README.md в папке проекта. Создай его в Блокноте или Thonny:

# Космический шутер

Игра на Python и Pygame Zero. Управляй кораблём и сбивай врагов.

## Как запустить
1. Установить Python и pgzero
2. Запустить space.py

## Управление
Стрелки — летать, пробел — стрелять

Автор: Андрей

Строчки с # станут заголовками.
