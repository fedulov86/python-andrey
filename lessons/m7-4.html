Работа по шагам

Шаг, проверка, commit

Ритм работы

Каждое занятие над проектом идёт по одной схеме:

  1. Посмотри план. Выбери следующий шаг.
  2. Сделай его. Запускай игру как можно чаще.
  3. Шаг работает — сделай commit с описанием шага.
  4. Вычеркни шаг в плане.

Описание commit пиши так, чтобы через месяц было понятно: «Враги появляются сверху», «Добавил звук выстрела». Не пиши «правки» или «123».

Если всё сломалось

Если ты что-то поменял и игра перестала работать, а как починить — непонятно, в GitHub Desktop можно отменить все изменения с последнего commit. Справа вверху на вкладке Changes нажми правой кнопкой на файл и выбери Discard changes. Файл станет таким, как при последнем сохранении.

Поэтому commit нужно делать часто: каждый раз, когда что-то заработало.

История

Вкладка History показывает все твои commit. Можно щёлкнуть на любой и посмотреть, что тогда поменялось.

Задачи

  1. Сделай все главные шаги своего плана, по commit на каждый.
  2. Нарочно сломай игру и верни её через Discard changes.
  3. Посмотри в History, сколько строчек ты добавил за всё время.
