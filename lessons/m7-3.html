Git: сохраняем версии

Машина времени для кода

Зачем это нужно

Бывает так: игра работала, ты что-то поменял, и всё сломалось. А как было раньше — уже не вспомнить. Программисты решают это программой Git. Она сохраняет версии проекта, как сохранения в игре. К любой версии можно вернуться.

Мы будем пользоваться GitHub Desktop — это Git с понятными кнопками.

Устанавливаем (вместе с папой)

  1. Зарегистрируйся на github.com. Это сайт, где программисты хранят свои проекты.
  2. Скачай и установи GitHub Desktop.
  3. При первом запуске войди в свой аккаунт GitHub.

Первое сохранение

  1. В GitHub Desktop: File → New repository. Репозиторий — это папка проекта, за которой следит Git.
  2. Name — название проекта английскими буквами, например space-shooter. Local path — твоя папка python. Нажми Create repository.
  3. Положи в новую папку файл своей игры и папку images.
  4. GitHub Desktop покажет слева новые файлы. Внизу слева в поле Summary напиши, что сделал: «Окно и корабль».
  5. Нажми Commit to main. Commit — это и есть сохранение версии.

Задачи

  1. Создай репозиторий для своего проекта и сделай первый commit.
  2. Поменяй что-нибудь в игре, сохрани файл и посмотри в GitHub Desktop: зелёным показано, что добавилось, красным — что убрано.
  3. Сделай второй commit с понятным описанием.
