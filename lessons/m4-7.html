Клик мышью

Черепашка идёт туда, куда щёлкнул

Где щёлкнули

Мышь работает так же, как клавиши: говоришь, какую функцию вызвать при щелчке. Отличие одно: функция получает два параметра — координаты места, куда щёлкнули.

11from turtle import *

shape("turtle")
color("blue")

def go_there(x, y):
    goto(x, y)

onscreenclick(go_there)

done()

Щёлкай по окну: черепашка будет ползти к каждому месту и рисовать линию. Получается рисовалка.

Координаты

Центр окна — точка (0, 0). x растёт вправо, y — вверх. Слева от центра x отрицательный, внизу отрицательный y.
