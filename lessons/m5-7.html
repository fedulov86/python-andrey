Мир из комнат

В текстовых играх мир состоит из комнат. В каждой комнате есть описание и выходы в другие комнаты. Это удобно хранить словарём, где каждая комната — тоже словарь.

30rooms = {
    "зал": {
        "text": "Большой зал замка. На стенах факелы.",
        "exits": {"север": "библиотека", "восток": "кухня"},
    },
    "библиотека": {
        "text": "Пыльные книги до потолка.",
        "exits": {"юг": "зал"},
    },
    "кухня": {
        "text": "Пахнет супом. Повар куда-то ушёл.",
        "exits": {"запад": "зал"},
    },
}

current = "зал"

while True:
    room = rooms[current]
    print()
    print(room["text"])
    print("Выходы:", ", ".join(room["exits"]))

    command = input("> ").strip().lower()
    if command == "выход":
        break
    elif command in room["exits"]:
        current = room["exits"][command]
    else:
        print("Туда не пройти")

Как это работает

  • В переменной current лежит название комнаты, где сейчас игрок.
  • rooms[current] достаёт словарь этой комнаты: текст и выходы.
  • Выходы — тоже словарь: направление и куда оно ведёт. Если игрок ввёл направление, которое есть в выходах, current меняется на новую комнату.
  • ", ".join(...) склеивает названия выходов через запятую.

Нарисуй карту на бумаге: квадратики-комнаты и стрелки между ними. С ней гораздо проще писать словарь.
